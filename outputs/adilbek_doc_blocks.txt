0136	Normal	ORDA жобасы классикалық веб-архитектура бойынша құрылған: клиенттік бөлік HTML, CSS және JavaScript арқылы жасалады, ал серверлік бөлік Node.js ортасында Express.js фреймворкімен жұмыс істейді. Сервердегі middleware қабаты қорғалған маршруттарға тек авторизацияланған пайдаланушыны, ал әкімші маршруттарына тек admin рөлін өткізеді [2, 3].

0139	Normal	Node.js серверлік JavaScript ортасы ретінде жобаның backend бөлігін құруға мүмкіндік берді. 0140	Normal	MongoDB құжаттық деректер қоры ORDA жобасының объектілік табиғатына сәйкес келеді. Mongoose бұл икемділікті сақтай отырып, схема деңгейінде міндетті өрістерді, типтерді және enum мәндерін бақылауға мүмкіндік береді.

Бұл тәсіл интерфейсті сервер логикасынан бөледі: кейін мобильді қосымша немесе басқа frontend жасалса, сол API-ді қайта пайдалануға болады.
